# Использование изображений

Источник: пакет `ORASAKA_CURSOR_WEBSITE/assets` (см. его `manifest.json`). Файлы в `public/banners/` — побайтные копии оригиналов, без пересжатия; AVIF/WebP-производные формирует `next/image` при запросе.

| Файл | Где используется | Как | Примечание |
|---|---|---|---|
| `main.jpg` | Hero главной | `priority`, `object-contain`, осмысленный alt | **Временный кандидат**, не подтверждённый выбор. Замена — `brand.hero` в `src/config/brand.ts` |
| `devices.jpg` | Главная, блок «Устройства» | lazy, декоративный (`alt=""`) | Список платформ продублирован HTML |
| `support.jpg` | Главная (поддержка), `/support` | lazy, декоративный | Каналы поддержки продублированы HTML |
| `tariffs.jpg` | `/pricing` | lazy, декоративный | Надписи на баннере не заменяют условия; условия — HTML |
| `connect.jpg` | `/connect` | lazy, декоративный, 1280×416 | Шаги — HTML |
| `instructions.jpg`, `cabinet.jpg` | не используются | — | Не нужны текущей вёрстке; при необходимости скопировать из пакета |
| `trial.jpg` | **не используется** | — | Надпись справа обрезана в оригинале; пробный доступ — только HTML и только по capability `trial` |
| `partners.jpg` | **не используется** | — | Реферальная программа показывается только по capability `referral`, сейчас выключена |
| `servers.jpg` | **не используется** | — | География серверов не публикуется на сайте |
| `legacy/*.png` | **не используются** | — | Прежний неаниме-стиль |

Логотип: отдельного утверждённого файла нет. В шапке — HTML-знак «ORASAKA VPN» (`brand.logo = null`). Знак из баннеров не вырезался и не дорисовывался. Иконка вкладки (`src/app/icon.svg`) — нейтральная геометрическая заглушка, не логотип.

Все баннеры выводятся целиком (`object-contain`), не обрезаются по лицам, знакам и тексту. Ни одно изображение не является единственным источником информации.
