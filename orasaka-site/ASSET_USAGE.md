# Использование изображений

Источник: пакет `ORASAKA_CURSOR_WEBSITE/assets` (см. его `manifest.json`). Файлы в `public/banners/` — побайтные копии оригиналов, без пересжатия; AVIF/WebP-производные формирует `next/image` при запросе.

| Файл | Где используется | Как | Примечание |
|---|---|---|---|
| `main.jpg` | Не выводится целиком. Из него вырезаны два кадра в `public/brand/` (ниже) | — | Надписи справа запечены в картинку, поэтому баннер целиком в hero не ставится |
| `brand/heroine.jpg` | Hero главной (`BrandIllustration variant="hero"`) | Кадр 552×720 из `main.jpg` (x 0–552, без текста), `priority`, `fetchpriority=high`, осмысленный alt; `object-cover` с фокусом на лице (mobile 2:1, tablet 5:4, desktop 4:5) | Лицо не обрезается ни на одной ширине. Движение: «дыхание» 3 px, отдельное свечение, параллакс ≤3 px (персонаж) и ≤10 px (свечение) только для мыши ≥1024 px |
| `brand/heroine-portrait.jpg` | Шапки `/account` и `/support` (`variant="compact"`, ≥640 px) | Кадр 330×330 (лицо и плечи), статичный, lazy | Никогда не ставится поверх форм, сумм и кнопок |
| `devices.jpg` | Главная (блок «Устройства», карточка «Мир ORASAKA»), `/devices` | lazy, декоративный (`alt=""`) | Список платформ продублирован HTML |
| `support.jpg` | Главная (поддержка), `/support` | lazy, декоративный | Каналы поддержки продублированы HTML |
| `tariffs.jpg` | `/pricing`, карточка «Мир ORASAKA» | lazy, декоративный | Надписи на баннере не заменяют условия; условия — HTML |
| `connect.jpg` | `/connect` | lazy, декоративный, 1280×416 | Шаги — HTML |
| `instructions.jpg` | Главная, карточка «Инструкции» → `/connect` | lazy, декоративный | Шаги — HTML |
| `cabinet.jpg` | Главная, карточка «Кабинет» → `/account` | lazy, декоративный | Функции кабинета — HTML |
| `trial.jpg` | **не используется** | — | Надпись справа обрезана в оригинале; пробный доступ — только HTML и только по capability `trial` |
| `partners.jpg` | **не используется** | — | Реферальная программа показывается только по capability `referral`, сейчас выключена |
| `servers.jpg` | **не используется** | — | География серверов не публикуется на сайте |
| `legacy/*.png` | **не используются** | — | Прежний неаниме-стиль |

Логотип: отдельного утверждённого файла нет. В шапке — HTML-знак «ORASAKA VPN» (`brand.logo = null`). Знак из баннеров не вырезался и не дорисовывался. Иконка вкладки (`src/app/icon.svg`) — нейтральная геометрическая заглушка, не логотип.

Баннеры выводятся целиком (`object-contain`) и не обрезаются по лицам, знакам и тексту; кадры героини в `public/brand/` — осознанные кропы без текста. На ширине < 640 px вторичные баннеры главной скрыты (мелкий запечённый текст там не читается). Нужный от владельца файл для честной композиции «героиня поверх фона» — `heroine.png` с альфа-каналом (см. README_ORASAKA.md). Ни одно изображение не является единственным источником информации.
